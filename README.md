# CA Lab Test — Q3: File Handling

## Task

A file `input.txt` (provided) contains a few lines of text. Write a script `index.js` that:
a) Reads `input.txt` and prints its contents to the console.
b) Writes that same content into a new file `output.txt`.
c) Appends the line `-- End of Notes --` to `output.txt`.
d) Reads `output.txt` again and prints its final contents to the console.
